Map tools

No map

Rebuild a whole map outside the game: export where every model sits, export those models, then add splines and Radiant brushes. Load the map with Load game first.

01Model placements

Writes static_models.json: every placed model with its position, rotation and scale.

Export model placements BO4 · CW
Cold War can also include entities, lights, probes and effects.

02Models from placements

Exports each unique model named in a placements file once, as CAST, with images and material info beside it. Interrupted runs can resume.

Export models from JSON BO4 · CW
Choose static_models.json, non_static_models.json or a per-class model file. Needs XModels loaded.

03Spline models

Bakes models that bend along splines (roads, pipes, cables) into real meshes in your selected model formats.

Bake spline models CW
You'll pick two files: the placements JSON, then splined_models.json from the same map session. Turn on Splined model inputs under Settings → Cold War research to capture them.

04Radiant brushes

Turns the map's collision into Radiant brush prefabs: brushes, clips, volumes and triggers in separate files.

Export brushes BO4 · CW
BO4 and Cold War use named BO3 stock clip and tool materials, with substitutions listed in the export report. BO4 visible surfaces keep their source materials and textures; unavailable materials are reported without a replacement.

Settings

Changes save immediately. Library changes apply the next time you load a game.

Diagnostics

Checks and raw captures for troubleshooting and research. Every run writes a report into its own folder under diagnostics.

Check export runtime
Verifies the bundled tools and Python dependencies are installed and intact.
Check a saved export
Pick a brush export_report.json or terrain research_capture.report.json to confirm no file changed.

Terrain source capture

Saves the raw TerrainGfx data for every loaded terrain without building models. Enable TerrainGfx in Settings → Library first.

Capture raw terrain source BO4 · CW
Output goes to dev_tools/terrain_sources.
